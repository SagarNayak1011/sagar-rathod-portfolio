# Sagar Rathod – Product Manager Portfolio

Static, zero-build site (HTML + CSS + JS, Three.js from CDN). Photos are already in `images/`.

## Update links
In `index.html`, replace each `href="#"` for Resume / LinkedIn / Portfolio with your real URLs.

## Push to GitHub
```bash
git init
git add .
git commit -m "Portfolio"
git branch -M main
git remote add origin https://github.com/<your-username>/portfolio.git
git push -u origin main
```

## Deploy on Vercel (free)
1. vercel.com → sign in with GitHub.
2. Add New → Project → import the `portfolio` repo.
3. Framework Preset: **Other**. Leave build/output empty.
4. Click **Deploy**.
